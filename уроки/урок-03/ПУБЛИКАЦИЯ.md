# 🚀 Урок 3. Публикуем сайт в интернет

Цель: получить **живую ссылку** на сайт груминг-ателье, которую можно
открыть на телефоне, компьютере и скинуть кому угодно.

> 👨‍👩‍👦 Позови родителя — момент с интернетом лучше пройти вместе.

---

## Способ А — Netlify Drop (самый быстрый, 1 минута)

1. Открой в браузере: **https://app.netlify.com/drop**
2. Открой Finder и найди папку с сайтом:
   `Документы → Проекты → ДимДимыч → dimdim → проекты → грум-ателье`
3. **Перетащи папку `грум-ателье`** мышкой прямо на страницу Netlify
   (туда, где написано «Drag and drop your site output folder here»).
4. Подожди несколько секунд — Netlify выдаст ссылку вида
   `https://весёлое-имя-1234.netlify.app`
5. Открой ссылку → нажми «🐾 Подобрать грумера» → **окно всплывёт, всё работает!** 🎉

> Чтобы сайт остался навсегда и получил имя покрасивее — нажми «Sign up»
> и зарегистрируйся бесплатно (лучше на почту родителя). Без регистрации
> ссылка тоже работает, но живёт временно.

---

## Способ Б — GitHub Pages (постоянный дом + красивая ссылка)

Делаем с родителем, всё в браузере, перетаскиванием мышкой. Заведём
отдельный репозиторий только под этот сайт — тогда ссылка будет чистой.

1. Зайди на **https://github.com** и войди (или зарегистрируйся с родителем).
2. Справа вверху **«+» → «New repository»**.
3. Имя репозитория: **groom-atelier**, поставь **Public**, нажми **Create repository**.
4. На странице пустого репозитория нажми ссылку **«uploading an existing file»**.
5. Открой Finder: `Документы → Проекты → ДимДимыч → dimdim → проекты → грум-ателье`.
   **Перетащи из неё файл `index.html`** в окно GitHub (только файл, не папку).
6. Нажми зелёную кнопку **«Commit changes»**.
7. Вкладка **Settings → Pages**.
8. Source = **Deploy from a branch**, Branch = **main**, папка = **/ (root)** → **Save**.
9. Через 1–2 минуты вверху появится твоя ссылка:
   **`https://<твой-логин>.github.io/groom-atelier/`**

> Совет: как только заведёшь вход в GitHub, я смогу помогать отправлять
> обновления сайта прямо отсюда — станет ещё быстрее.

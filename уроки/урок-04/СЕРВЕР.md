# 🔒 Урок 4. Прячем токен бота на сервере (Cloudflare Worker)

Цель: сделать так, чтобы токен бота **не лежал в коде сайта**. Вместо этого
сайт будет отправлять заявку на маленький бесплатный сервер, а сервер —
в Telegram. Токен спрятан = безопасно. Делаем с родителем.

## Идея простыми словами
```
Сайт  →  наш сервер (прячет токен)  →  Telegram
```

---

## Шаг 0. Новый токен (старый «засветился»)
Старый токен мы использовали в переписке — считаем его небезопасным.
1. Открой @BotFather → /mybots → выбери бота → **API Token** → **Revoke current token**.
2. BotFather выдаст **новый токен**. Его НИКУДА не вставляй в сайт и не пиши в чат —
   он пойдёт только в секрет сервера (Шаг 4).

## Шаг 1. Регистрация Cloudflare (бесплатно)
1. Зайди на **https://dash.cloudflare.com/sign-up**
2. Зарегистрируйся (лучше на почту родителя), подтверди email.

## Шаг 2. Создать Worker
1. Слева выбери **Workers & Pages** → **Create** → **Create Worker**.
2. Придумай имя, например **groom-bot** → **Deploy**.

## Шаг 3. Вставить код
1. Нажми **Edit code**.
2. Удали то, что там есть, и вставь код из файла
   [`server/telegram-worker.js`](../../проекты/грум-ателье/server/telegram-worker.js).
3. Нажми **Deploy** (сохранить).

## Шаг 4. Добавить секреты (токен и chat_id)
1. Вернись к воркеру → **Settings** → **Variables and Secrets**.
2. Добавь переменную **BOT_TOKEN** = новый токен из Шага 0 (тип Secret).
3. Добавь переменную **CHAT_ID** = `8969341722` (тип Secret).
4. Сохрани / нажми Deploy.

## Шаг 5. Скопировать адрес сервера
1. На странице воркера будет ссылка вида
   **`https://groom-bot.ТВОЙ-ЛОГИН.workers.dev`**
2. Скопируй её и **пришли мне в чат.**

---

## Что дальше
Как пришлёшь адрес — я поменяю сайт, чтобы он отправлял заявку **на этот сервер**
(а не прямо в Telegram с токеном). После этого:
- в коде сайта токена больше НЕ будет → сайт безопасный;
- заявки будут так же приходить тебе в Telegram;
- и мы наконец сохраним весь проект на GitHub.

> ⚠️ Пока сервер не готов — **не загружай новый сайт на GitHub**: в нём ещё лежит токен.
